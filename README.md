# Світлиця — лендінг, друга спроба

Кав'ярня і коворкінг у Черкасах, які створює громадська організація «Світлиця».

Перша версія: [ElojahBryhodan/svitlitsa](https://github.com/ElojahBryhodan/svitlitsa).
Дизайн тут починається з нуля; звідти перенесено тільки активи й правила.

## Що вже є

```
assets/logo/      знак, вордмарк, орнамент, фавікон — вектор із фірмового PDF
assets/images/    7 файлів .webp (4 основні + 3 дрібні варіанти)
design-system.md  дизайн-система «Світлиця» v2.0 — джерело тексту (§1)
BRAND.md          виміряні фірмові факти: геометрія логотипа, кольори, правила
tools/verify.py   звірка тексту сторінки з §1, посимвольно
```

Верстки поки немає — вона й буде новим дизайном.

## Перевірка контенту

```bash
python3 tools/verify.py index.html
```

Текст ГО недоторканний, вигадані числа й контакти заборонені. Деталі — у `BRAND.md`.
