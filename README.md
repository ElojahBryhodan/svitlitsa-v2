# Світлиця — лендінг

Кав'ярня і коворкінг у Черкасах, які створює ГО «Світлиця».

- **GitHub Pages:** https://elojahbryhodan.github.io/svitlitsa-v2/
- **Vercel:** https://svitlytsia-gamma.vercel.app

## Як підняти локально

Звичайна статика без збірки. Через `file://` не запрацює — потрібен сервер.

```bash
python3 -m http.server 4217
```

Далі відкрити http://localhost:4217

## Структура

```
index.html            вся розмітка (українською, контент дослівний)
assets/v3.css         стилі
assets/v3.js          скрипти, анімації на GSAP
assets/img/           фото: hero-tall, cafe, coworking, final + partners/p1…p10
assets/brand/         лого і орнаменти у SVG
vercel.json           заголовки кешування для Vercel (на Pages не діє)
.nojekyll             щоб Pages віддавав файли як є, без обробки Jekyll
design-system.md      джерело тексту §1
BRAND.md              правила щодо контенту й фірмові факти
tools/verify.py       звірка тексту сторінки з §1
```

Зовнішні залежності з CDN: GSAP 3.13 + ScrollTrigger + SplitText,
шрифти Unbounded і Onest з Google Fonts. Npm-залежностей і бекенду немає.

## Що варто знати перед правками

- **Анімації** увімкнені лише коли на `<html>` є клас `motion`. Клас не
  додається при `prefers-reduced-motion`, і тоді сторінка показує статичний
  фінальний стан. Будь-яка нова анімація мусить мати робочий статичний варіант.
- **Хіро.** Монограма «Ц» — це SVG-стіна з вирізом (`.door`), крізь який видно
  фото. Геометрія перераховується з JS від розмірів `.hero__slot`, тому не
  задавати прорізу фіксовані пікселі.
- **Кроки «Як твоя чашка допомагає».** Помаранчевий прямокутник `.token` —
  окремий елемент, що стрибає між картками; картки під ним стають прозорими
  (`.flow__item.is-on`).
- **Фінал.** Секція висотою 260svh зі `sticky` всередині: фото розкривається
  через `clip-path`, далі темніє і проявляється знак.
- У посиланнях на файли є `?v=<число>` — версія збірки, оновлюється разом
  із файлами.

## Перевірка контенту

```bash
python3 tools/verify.py index.html
```

Текст недоторканний, вигадані числа й контакти заборонені — деталі в `BRAND.md`.
